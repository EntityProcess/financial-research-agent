# Financial Research Skills

These skill cards describe target-agent behavior for this AgentV companion eval
project. AgentV remains the harness; these files teach the public financial
research target how to answer, calculate, cite, and package research.

The skills were written as original, portable guidance after inspecting Dexter at
pinned commit `8d9419829f443f84b804d033bb2c3b1fbd788629`. Dexter did not include a
standalone license file at that commit, and `package.json` did not declare a
license field, but Dexter's README states that the project is MIT licensed. This
repository does not copy Dexter source, provider internals, private API
assumptions, or SKILL.md prose. Dexter remains fixture provenance and an optional
compatibility target only.

- `financial-research/` — default public benchmark answer workflow.
- `dcf-valuation/` — valuation checklist and sanity checks.
- `investment-memo/` — memo/thesis workflow.
- `market-sentiment/` — public sentiment workflow.
